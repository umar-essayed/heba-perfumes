## 🌟 مميزات المتجر (ليه متجر هَيْبَة مختلف؟)

### 1. هوية بصرية مريحة وفخمة (Quiet Luxury)
- ألوان راقية مستوحاة من شعار هَيْبَة الملكي: الأسود الفاحم، الذهب الدافئ (`#C5A880`)، والتدرجات البرونزية، بدون أي إضاءات نيون مزعجة أو فلاشات أو كلام مصطنع من الذكاء الاصطناعي.
- دعم كامل لتجربة الموبايل: عرض كارتين في كل صف بأسلوب متناسق غير متماثل (Asymmetric Staggered Grid) مستوحى من كبرى دور الأزياء العالمية.
- بطاقات عطور ذكية تميز بصرياً بين الرجالي والحريمي مع صور مخصصة لكل فئة.

### 2. تجربة شراء مصرية سهلة ومطمئنة
- **عاين مع المندوب واطمن:** توضيح صريح في كل خطوة بحق العميل في فحص الزجاجة والتأكد من التركيز والفوحان.
- **تغليف الهدايا الملكي مجاناً:** إمكانية تحديد الطلب كهدية مع كتابة كارت إهداء راقي وتغليف كرافت فاخر.
- **شحن مجاني تلقائي:** لأي سلة مشتريات تتجاوز 900 جنيه، مع حساب دقيق لأسعار الشحن لـ 25 محافظة مصرية.

### 3. طرق دفع متطورة (كاش ومحافظ وإنستاباي)
- **الدفع عند الاستلام (COD):** الخيار الأساسي والمحبوب.
- **فودافون كاش والمحافظ الإلكترونية:** رقم الكاش المعتمد `01003508854` مع زر نسخ الرقم بنقرة واحدة (One-Click Copy) ومؤشر تفاعلي.
- **إنستاباي (InstaPay):** رقم الهاتف المسجل `01003508854` وعنوان IPA، مع إمكانية تعديل الأرقام كاملة من لوحة التحكم.

### 4. صفحة تتبع الطلبات التفاعلية (`/track-order`)
- تقرأ الطلبات المسجلة على جهاز العميل تلقائياً من الـ `localStorage` وتعرضها في بطاقات سريعة المتابعة.
- إمكانية البحث برقم الطلب (مثال: `HEBA-6602`) أو برقم الموبايل المصري بكافة صيغه (`010...` أو `+2010...`).
- خط زمني تفاعلي من 4 مراحل يوضح للعميل أين طلبه الآن (جديد ⬅️ قيد التجهيز والتعتيق ⬅️ مع المندوب ⬅️ تم التسليم).

## 🔐 لوحة التحكم الإدارية الشاملة (`/admin`)

لوحة تحكم معزولة تماماً عن واجهة المتجر العامة (تختفي النافبار والفووتر وزر الواتساب لتوفير بيئة عمل احترافية)، ومؤمنة بالكامل:
* **بوابة الدخول:** محمية برمز مرور وتوكن مشفر رقمياً (HMAC Signed Token) وجدار حماية ضد التخمين (Rate Limiting).
* **كلمة المرور الافتراضية:** `heba2026` (يمكن تغييرها عبر متغير البيئة `ADMIN_PASSWORD`).
* **إدارة الطلبات (Orders CRUD):**
  - استعراض حي لكافة الطلبات وتفاصيل العميل وأرقامه والعنوان.
  - تحديث حالة الطلب فوريًا في Firestore مع إضافة ملاحظات وتحديث التاريخ.
  - طباعة فاتورة وبوليصة شحن بتنسيق نظيف ومعد للطباعة المباشرة.
  - زر محادثة واتساب يفتح رسالة جاهزة باسم العميل وحالة طلبه.
  - إنشاء طلب يدوي من داخل اللوحة + إمكانية حذف أي طلب بعد التأكيد.
* **كتالوج العطور (Products CRUD):**
  - إضافة عطر جديد مع النوتات العطرية والأحجام والأسعار.
  - تعديل أي عطر موجود حالياً.
  - تفعيل أو إيقاف توفر العطر في المخزن (`In Stock / Out of Stock`) بنقرة واحدة.
  - حذف أي عطر من الكتالوج.
* **إدارة الكوبونات (Coupons CRUD):**
  - إنشاء كوبونات جديدة (نسبة مئوية أو مبلغ ثابت وحد أدنى للطلب).
  - تفعيل أو تعطيل أي كوبون لحظياً.
* **إدارة المحافظ وإنستاباي (Payments Settings):**
  - تعديل أرقام فودافون كاش ورقم إنستاباي ومعرف IPA واسم صاحب الحساب وتعليمات التحويل.
  - معاينة حية فورية (Live Preview) لشكل البطاقة كما ستظهر للعميل في التشيك أوت.
  - زر استعادة الأرقام الافتراضية بنقرة واحدة.

### 1. اختبارات الـ Unit والأمان والكتالوج (`npm test`)
```bash
npm test
```
- التحقق من قوة التشفير وتوليد توكنات الـ HMAC.
- فحص نظام حظر الـ IP عند تكرار المحاولات الخاطئة (Rate Limiting).

- التحقق الإلزامي من **حجب الأسعار تماماً** من بطاقات المشاركة والميتاداتا.
- فحص استقرار السلة وتخزين الـ LocalStorage.

### 2. فحص دورة الحياة الشاملة في Firestore (`npm run test:e2e`)
```bash
npm run test:e2e
```
يقوم السكريبت باختبار حي وتفاعلي كامل عبر 9 مراحل:
1. فحص الاتصال الحي بـ Google Firebase Firestore.
2. التحقق من صلاحية وحساب كود الخصم (`HEBA10`).
3. إنشاء طلب جديد كعميل وحفظه كاملاً في Firestore.
4. تتبع الطلب برقم الأوردر وبكافة صيغ أرقام الموبايل المصرية (+20).
5. تسجيل دخول الإدارة والتحقق من الحماية وصدور التوكن.
6. تحديث حالات الطلب (جديد ⬅️ تجهيز ⬅️ شحن ⬅️ تسليم) وحفظ الخط الزمني في Firestore.
7. التأكد من قراءة صفحة التتبع للحالة المسلمة وللمراحل الأربعة بدقة.
8. حذف طلب الاختبار والتنظيف التام من قاعدة البيانات مع التأكد من إرجاع 404.
9. قراءة وتحديث واستعادة إعدادات المحافظ وإنستاباي في Firestore.

## 🚀 التشغيل والتثبيت محلياً (Installation)

### 1. استنساخ المستودع وتثبيت المكتبات
```bash
git clone https://github.com/YOUR_USERNAME/heba-perfumes.git
cd heba-perfumes
npm install
```

### 2. إعداد ملف البيئة
```bash
cp .env.example .env.local
```
*(ضع ملف Service Account الخاص بـ Firebase Admin في المجلد الرئيسي بإسم `heba-7747d-firebase-adminsdk-fbsvc-f410094cd3.json`)*.

### 3. زراعة البيانات في Firebase Firestore
```bash
npm run seed
```

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000)  
لوحة التحكم: [http://localhost:3000/admin](http://localhost:3000/admin) (كلمة السر: `heba2026`).

1. ارفع المشروع إلى GitHub (مفتاح الـ Firebase الخاص محمي تلقائياً عبر `.gitignore`).
2. اربط المستودع في Vercel أو أي منصة سحابية.
3. في خانة الـ Environment Variables أضف:
   - `ADMIN_PASSWORD` = `heba2026`
   - `ADMIN_SESSION_SECRET` = مفتاح تشفير عشوائي قوي.
   - `FIREBASE_PROJECT_ID` = `heba-7747d`
   - `FIREBASE_SERVICE_ACCOUNT_JSON` = محتوى ملف الـ json كاملاً لتشغيل الـ Admin SDK سحابياً بدون ملفات محلية.
